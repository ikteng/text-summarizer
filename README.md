# Flutter Text Summarizer

A mobile-friendly text summarization app built with Flutter. Users can paste text or upload documents to extract and summarize content, then view, copy, or download the summaries.

---
## Usage
1.Paste Text
    Enter the text you want summarized in the input box.

2. Upload File
    Choose a file (.txt) to extract text.

3. Summarize
    Tap the Summarize button to generate a summary.

--

## Installation

1. clone the reponsitory
2. run `flutter run`
3. make sure the backend is running
